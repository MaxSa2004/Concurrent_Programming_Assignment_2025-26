To compile/run the code for exercises 1.1 - 1.4 do the following:
    
1. Go to: https://pseuco.com/
2. Click the blue "Get Started" button.
3. Click the green "Create new CCS File" button.
4. Click the green "Create new empty file" button.
5. Copy and paste the code into the CCS code input on the left-hand side.
6. Click "Expand all" in the bottom right corner to view the full LTS of the code.
