To compile/run the code for exercises 2.1 - 2.4 do the following:

1. Open the folder '/process-simulator/server' in your terminal.
2. Enter the command 'sbt run' to start the server.
3. Go to the folder '/process-simulator/client' and open 'index.html' in your web browser.
4. Write your input programs in the area provided on the left side of the page and open the "Request simulations" window to execute your input program.
5. Open the "Status (every 2s)" window to see the results.
